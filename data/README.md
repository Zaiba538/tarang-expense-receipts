# Data Directory Documentation

## Overview

This directory contains the input data and supporting files used by the Tarang Pharma expense receipt review project.

## Task Data

The task files are located in `data/Task 2 Files/`.

| File | Purpose |
|---|---|
| `claims_train.csv` | Training claims with historical status information and clerk-recorded receipt fields. |
| `claims_test.csv` | Test claims for which predictions must be generated. |
| `employees.csv` | Employee information used by applicable policy checks. |
| `sample_submission.csv` | Required prediction output format. |
| `expense-policy.pdf` | Expense policy reference document. |
| `email-thread.txt` | Supporting task correspondence. |

## Receipt Images

Downloaded receipt images are stored in the project's `images/` directory, if available. Image matching results are recorded in `reports/image_match_report.csv`.

Not every claim necessarily has a matching image. A missing image must not be treated as proof that a claim is invalid.

## Generated Data

The project creates intermediate and evaluation outputs under `reports/`, including:

- `ocr_extractions.csv`
- `image_match_report.csv`
- `test_claim_receipt_matches.csv`, if generated
- `training_evaluation.csv`
- `evaluation_summary.txt`

These files are generated by the project's scripts and may need to be regenerated after changes to source data or extraction logic.

## Data Handling

- Preserve original input files.
- Do not fabricate missing receipt values.
- Keep employee information and receipt images confidential.
- Do not commit API keys, credentials, or signed download URLs.
- Verify OCR-extracted values against the original receipt when accuracy matters.
- Treat historical claim statuses as reference labels, not independently verified policy-compliance ground truth.

## Reproducibility

Run the extraction, matching, evaluation, and prediction scripts from the project root. Refer to the root `README.md` for commands and execution instructions.
